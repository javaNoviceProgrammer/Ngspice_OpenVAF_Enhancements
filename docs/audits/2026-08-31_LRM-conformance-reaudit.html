1The verdict

The morning's roughest edges are gone; what remains different from the LRM is now chosen, spoken, and pinned.

The original audit's most consequential group — eleven silent-wrong-answer findings — is empty. Every one was re-measured today with the committed binaries and produces the LRM-required number: defparam survives a generate construct (−8 mA, was −2 mA), #(.$mfactor(4)) scales the child (−4 mA, was −1 mA), $param_given sees hierarchy overrides (−7 mA, was −99 mA), two same-labelled noise calls power-sum (1.414 µV/√Hz, was an exact 0), ac_stim("ac") stays out of the noise gain solve, and the misspelled event that used to run on every evaluation is a located error.

The lifecycle boundary — where the first audit found its densest cluster — now holds: display and file I/O defer to accepted iterations (a diode .op prints one $strobe line at the converged point, not fifteen along the Newton walk), the transient operating point reports ic=1 static=1 at t = 0 and zeros at every timepoint, cross()/above() follow their normative timing rules, and $bound_step honors the smallest active bound in either call order.

Both compiler crashes are gone, all 39 confirmed bugs are fixed to the letter of the cited clauses, and none of the 15 remediation enhancements broke anything the audit had verified as conformant: the 443-suite sweep — which includes every pre-audit suite — passes on the same binaries that pass the re-measurements below.

These are not smoke tests; they carry the audit's own numbers (the Table 5-1 five-analysis matrix, the √2 noise power sum, the ragged-isoline table file, a spec-conformant fake OSDI v0.3 object the suite compiles itself).

An independent re-measurement of the original evidence. The audit's headline findings quoted concrete measured numbers. Eighteen of them were re-reproduced today from scratch — fresh decks, written without reference to the suites, run against the committed bin/macos/apple-silicon/ binaries. All 18 produce the LRM answer (§3).

The regression estate. The full 443-suite example sweep (ALL OK), the compiler's fast (211) and slow (237) cargo test suites, and the 13-model CMC compile corpus (zero warnings) — all green on the same binaries. This is what rules out fixes that traded one clause for another.

5What happened to each finding class

39 bugs — all fixed to the cited clause

Both ICEs compile or reject cleanly (string-typed functions work end to end; function-local parameters follow the 4.7.1 shadowing rule). The five silent hierarchy bugs produce the LRM numbers (§3). The event machinery follows Table 5-1 exactly — the suite runs the full five-analysis matrix — and cross() stays quiet in DC while above() fires its mandatory initialization event. Display, $monitor change detection, %r, file-write deferral and the append-on-reopen rule all follow 9.4/9.5. The nature-attribute validation runs (it was dead code), the OSDI natures table counts attributes correctly, discipline compatibility implements all six rules of 3.11.1, and `undef can no longer remove predefined macros. On the simulator side, v0.3 objects are rejected with a recompile message instead of being misread, and the phantom IFparm row is gone.

28 deviations — promoted to the LRM or kept and made explicit

Promoted — the LRM behavior is now the behavior: absdelay freezes td when maxdelay is absent; transition completes at td + trise regardless of amplitude and explicit zeros consult `default_transition; out-of-range cross dir means "no event", not $fatal; analysis("dc") is 0 at AC/noise operating points; same-labelled noise calls are uncorrelated (the label groups reporting only); $limit with an unknown name falls back to unlimited evaluation with a warning; no-default $simprobe is the 9.16 error; the 9.13.2 distribution domains abort with the mandated runtime error; alias-plus-original overrides and the other 3.4.7 rules are enforced.

Kept, now audible or documented — where the difference is a considered design position, it stays, and it now says so: stateless limexp and the bilinear zi_* filters (disclosed, quantified); dynamic laplace coefficients tracking (audible); the parameter-default range exemption; the untyped-parameter freeze; contributions inside runtime loops and out-of-scope named-block access as accepted extensions; m=0 as the disable-this-instance idiom; the $bound_step (tstop−tstart)/1e6 per-model floor (⚠️ in the compliance doc and README_OSDI). Every kept deviation is pinned by a suite check so it cannot drift silently.

24 missing — implemented, or refused with located diagnostics and documented

Implemented since the audit: jump statements (break/continue/return, as 2023 contextual keywords), white-space and macro-substituted based literals, `__VAMS_ENABLE__, `begin_keywords/`end_keywords, `__FILE__/`__LINE__ inside includes (with the include-resolution bug fixed), the comma event-OR separator, string→integer conversion, the NIST2018 constants selection in constants.vams, analysis("nodeset"), ddx of an unnamed flow probe, and the whole missing $table_model surface — the normative 9.21.1 file format with ragged isolines, closest-point D with the 9.21.4 tie rule, E, per-end and per-dimension controls, ;N, and the 1-D array pair — plus $simparam$str("analysis_type") and ("cwd").

Still refused, now honestly: multi-construct generate regions, descending genvar loops, hierarchical refs into generate instances, paramset overloading and paramset output variables, macromodule, vector branches, upward hierarchical references, child port-net access, noise_table's parameter-fed forms, $table_model's 2/I controls, and the multichannel/pre-opened descriptor model. Each is a located diagnostic, and each is now listed in the compliance doc's per-area gap notes rather than sitting under a blanket ✅.

9 doc mismatches — the compliance doc now matches the binaries

All nine corrected in place, and the affected sections rewritten rather than patched: §7.1 display (the %r/monitor/iteration claims), §6 hierarchy (fixes, ⚠️ transform limits, and the refusal list above), §5.5 events, the jump-statement claim (now describing the implemented feature), the three §4.5 operator claims, the $table_model section (clause number fixed to 9.21, example now one that compiles), the ac_stim radians example (`M_PI/2, not 90.0), the analog-function section, and the paramset clause reference (6.4). The doc's PDF is rebuilt as part of the release ceremony, so the shipped artifact matches.

6What deliberately remains outside the surface

The honest boundary after remediation — every item below is a located diagnostic or a documented bound, none is silent.

  • Generate/paramset structural gaps — multi-construct regions, descending genvar loops, refs into generate instances, paramset overloading and output variables, macromodule, module self-instantiation. Architectural: OSDI binds parameters at simulation time while these require parameter-dependent structure. Disclosed in the compliance doc §6.
  • Upward and port-net hierarchical references — only downward references into the compiled hierarchy resolve.
  • OSDI v0.3 objects — deliberately dropped, and the drop is now a clean printed rejection with a recompile message instead of a misread and a SIGSEGV. Recorded in README_OSDI's version-support section.
  • Kept semantic deviations — stateless limexp, bilinear zi_*, dynamic filter coefficients, the parameter-default range exemption, runtime-loop contributions, the $bound_step per-model floor. Each disclosed and suite-pinned.
  • Unservable identity queries — $simparam$str("module"/"instance"/"path"): the OSDI simparam channel carries no instance identity; the honest warn-then-fatal stands, documented with the reasoning.
